# 🎮 Tile Crawler - HashMaps & Tkinter Game

A Python 2D tile-based game designed to demonstrate practical applications of **HashMaps (Python `dict`)** in game state management and GUI design with **Tkinter**.

---

## 🌟 Features
- **$O(1)$ Spatial Lookup**: Grid coordinates `(x, y)` act as tuple keys in a HashMap for instant wall collisions and item collection.
- **Model-View Architecture**: Separation of raw HashMap game state from the Tkinter Canvas drawing logic.
- **Interactive Controls**: Navigate using `Arrow Keys` or `WASD`.
- **Slide Presentation**: Includes an embedded HTML presentation covering core data structure concepts.

---

## 🚀 How to Run the Game Locally

### Prerequisites
Make sure Python 3.x is installed on your computer. Tkinter comes pre-installed with standard Python distributions.

### Running the Game
```bash
git clone [https://github.com/YOUR_USERNAME/hashmap-tkinter-game.git](https://github.com/YOUR_USERNAME/hashmap-tkinter-game.git)
cd hashmap-tkinter-game
python game.py
